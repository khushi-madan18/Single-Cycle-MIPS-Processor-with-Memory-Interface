How to use the simulator

      

        

          
Workflow

          
    
            
  1. Pick a sample program or type your own assembly. It is assembled automatically as you type.
    2. 
            
  2. Press Step to execute one clock cycle (one whole instruction) and watch it travel through the datapath.
    3. 
            
  3. Open Conversion to see every step from assembly text to the 32-bit word, then how the hardware decodes and executes it.
    4. 
            
  4. RTL Verification compares each cycle with the real Verilog simulation (Icarus Verilog).
    5. 
          

          
Supported instructions

          
add sub and or slt · addi · lw sw · beq · j · nop · halt

          Directives: .data .text label: .word 1, 2, 3 .space n

        

        

          
Keyboard
